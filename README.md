### The utility doesn't start

- Make sure you're running Windows 10 or 11
- Check that you have the latest version from the download link
- Right-click the file and select **Run as Administrator**

### The game isn't detected

- Start the game first, then launch the utility
- Make sure the game is running in windowed or borderless mode
- Check if your antivirus is blocking the utility

### Settings don't apply

- Try running the utility as Administrator
- Make sure you click **Apply** after changing settings
- Restart both the utility and the game

### Hotkeys don't work

- Close other programs that might be using the same keys
- Check that the utility is running in the background
- Reassign the hotkeys in the utility's settings
